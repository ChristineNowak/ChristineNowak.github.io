## Über das Projekt

Die Website präsentiert Christine Nowaks berufliches Profil und ihre Leistungen an der Schnittstelle von **Hospitality Operations, Prozessoptimierung, Guest Experience, Teamtraining und Hoteltechnologie**.

Sie richtet sich an anspruchsvolle Hotels, Boutique-Hotels, Retreats sowie Hospitality-Tech-Unternehmen. Im Mittelpunkt stehen praxistaugliche Verbesserungen, die Menschen, Prozesse und digitale Systeme verbinden.

## Technische Umsetzung

- Statische Website mit HTML, CSS und wenig JavaScript
- Veröffentlichung über **GitHub Pages** mit eigener Domain
- Responsives Layout für Desktop und mobile Endgeräte
- Deutsche und englische Sprachversion mit gegenseitiger Verlinkung
- SEO-Grundlagen: Seitentitel, Meta-Beschreibungen, Canonical-URLs, `hreflang`, Sitemap und strukturierte Daten
- Open-Graph- und Twitter-Metadaten für Linkvorschauen
- Zugänglichkeitsfunktionen wie Tastaturfokus und Link zum Hauptinhalt
- Keine externen Analyse- oder Tracking-Skripte in den hier dokumentierten Startseiten
